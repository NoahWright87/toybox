# assets/sprites/enemies/

Hostiles, from drones up to bosses. Naming: `enemy_{name}_{state}_{frame}.png`
(e.g. `enemy_drone_idle_01.png`). Default canvas: 64×64; bosses use 128×128
(set `frameWidth`/`frameHeight` explicitly in the manifest entry) — see
`../../../sprites/README.md` for the full convention guide.

No art has been generated yet — every `enemies` sprite renders as its
manifest-declared colored placeholder primitive until a PNG lands here.
